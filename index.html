QuizVerse: Python quiz game

Desktop app · Python, Tkinter

A desktop quiz game with nine Python-focused categories, three difficulty levels and 270 questions in total. Players enter a name, pick a category and difficulty, and answer 10 timed multiple-choice questions.

  • Per-question countdown timer that moves to the next question automatically
  • Scoring with a result screen, play again option and a leaderboard saved in a local file
  • Answer review screen so players can go back through the questions they got wrong
  • Built as a single Tkinter window with a QuizApp class, split across three files for clarity
